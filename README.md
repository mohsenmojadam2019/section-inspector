# Section Inspector

Chrome/Chromium extension for inspecting a live website like a compact Figma Inspect panel.

Click any element to see exact size, position, section size, margin, padding, borders, colors, background image, radius, shadow, typography, display, position, z-index, overflow, flex/grid gap, alignments and grid tracks.

Actions: Parent, nearest Section, Copy CSS, Copy JSON, Refresh and Unpin.

Toggle with the extension icon or Alt + Shift + S.

No build step is required.
